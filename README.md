# Lightfarer BC: Christ Before the Manger

A contemplative learn-by-playing web game in which the player illuminates a cosmos of fourteen sanctums — thirteen person-stars across two orbital rings (Dawn and Ancient) plus the Logos sanctum at center — through Duolingo-cadence lessons that reveal the Christ-shape echoing across human mythohistory.

## Status

Prototype. Dawn ring (5 gods) is locked: Inanna, Osiris, Sophia, Vishnu, Nüwa. Outer ring (8 gods) generated and on the cosmos map but not yet wired to sanctums.

## Stack

- Plain HTML + JavaScript on Canvas (PixiJS upgrade planned per spec)
- No build step, no npm
- Static assets in `/assets`
- Hosted on GitHub Pages → lightfarer.com

## Running locally

Open `index.html` in any modern browser, or serve with `python3 -m http.server 8000`.
